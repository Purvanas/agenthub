    Consommation

    Ces chiffres ne couvrent que les turns lancés depuis agentHub, pas ce que tu fais depuis ton PC. Le coût est l'équivalent API : ce que la même consommation aurait coûté en facturation au token.

    Serveur

    Ces relevés viennent d'adminPanel, en lecture seule. Agir — relancer un service, bannir une IP, ouvrir un terminal — se fait dans le panneau, qui reste une application à part : c'est l'outil qu'on ouvre quand agentHub est cassé.

    Skills

    Règles de

    Nomme une règle d'après le geste qu'elle encadre — git push, déploiement, migration. À chaque turn, les agents de ce projet voient la liste des noms et lisent celle qui les concerne avant d'agir. C'est une consigne, pas un verrou : agentHub ne voit pas les commandes qu'un CLI lance depuis son propre outil.

    Secrets de

    Les agents qui travaillent dans ce dossier reçoivent ces valeurs dans leur environnement et connaissent le nom des clés. Ils s'en servent en écrivant $NOM dans leurs commandes. Toute valeur qui apparaîtrait dans une sortie est masquée avant affichage.

    Coller un fichier .env entier
    Les clés déjà présentes sont remplacées, les autres conservées.

    Une valeur enregistrée ne peut plus être relue ici, seulement remplacée : la renvoyer au navigateur la ferait traverser le réseau à chaque affichage.
